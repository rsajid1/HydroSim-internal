## Project Description

### Project Title: HydroSim 


HydroSim is a online web simulation tool designed for hydroponics applications. Growing plants at scale can be difficult as it requires many inputs and controls. Small variances in temperature, humidity or nutrient levels can affect the yield of plants. Our platform lets users model plant growth with these varying factors without real world consequences or costs. 

HydroSim's web application allows users to select a plant, and control inputs so they can simulate long-term growth in real time. The simulation shows how water levels, nutrients, and pH balances affect plant life. Changing the inputs allows the user to predict how plants would typically react to changes. The predictions of these outcomes are derived from previous datasets. 

The intended audience for HydroSim is students, hydroponics hobbyists and farmers. The goal is to gave users confidence in their hydroponic plans before they invest in physical equipment. Educators can also use the tool to demonstrate plant growth and provide interactive examples. HydroSim will lower the barrier to entry those interested in Hydroponics.
